## 這一頁在做什麼

顯示**每個機種總共出貨了幾台**，用長條圖呈現，數量最多的排最上面。

數字是資料庫裡的 `model_shipment_counts` view 事先算好的（依機種統計資料列數），網頁只要讀一次就拿到「機種＋數量」清單，不用把所有資料列下載回來自己算，所以很快。

---

## 一、共用工具

| 函式 | 行號 | 用途 |
|---|---|---|
| `escapeHtml(str)` | 1 | 把 `& < > " '` 轉成 HTML 安全字元。機種名稱、數量塞進畫面前都要先經過它，防止 XSS 攻擊 |
| `dbCall(op, params)` | 6 | **呼叫伺服器 `/api/db`**，資料庫查詢都透過它，瀏覽器不持有 key |
| `csvCell(v)` | 19 | 匯出 CSV 時處理每一格：以 `= + - @` 開頭的值前面加 `'`，避免 Excel 把它當公式執行（純數字除外） |
| `apiStatusDot`、`apiStatusText` | 25～26 | 頁面上方狀態燈和狀態文字的元素 |
| `setStatusBar(state, text)` | 27 | 更新狀態燈（綠：成功、紅：失敗、橘：讀取中）和文字 |

## 二、讀取資料

| 函式 / 變數 | 行號 | 用途 |
|---|---|---|
| `fetchModelCounts()` | 33 | 透過 `dbCall('modelCounts')` 讀出機種統計，轉成 `[[機種, 數量], ...]` 的格式。伺服器回傳時已經依數量由多到少排好 |
| `fullData` | 38 | 讀回來的完整機種清單 |
| `maxQty` | 39 | 最大的出貨量，用來計算每條長條圖的長度 |

## 三、畫面

| 函式 | 行號 | 用途 |
|---|---|---|
| `renderList(list)` | 41 | **畫出機種清單**。每一列有：機種名稱、長條圖、數量。長條長度 = 這個機種的數量 ÷ 最大數量，所以第一名永遠是滿格。清單是空的時候顯示「找不到符合的機種」 |
| `updateSummary(list, totalQty)` | 58 | 更新上方統計摘要：**機種數**和**總出貨量**（加上千分位逗號，例如 `31,479 台`） |

## 四、載入資料

| 函式 | 行號 | 用途 |
|---|---|---|
| `loadData()` | 64 | **頁面主要的載入流程**（見下方） |

**`loadData()` 的流程：**
1. 隱藏錯誤和統計摘要，顯示「正在讀取資料…」，狀態燈變橘色。
2. 用 `fetchModelCounts()` 讀出機種統計。
3. 狀態燈變綠色。
4. 取第一筆的數量當作 `maxQty`（因為已經由多到少排序，第一筆就是最大的）。
5. 把所有機種的數量加總，用 `updateSummary()` 更新摘要。
6. 用 `renderList()` 畫出清單。
7. 失敗時狀態燈變紅，並顯示「讀取失敗：…」。

## 五、搜尋開關（你加的）

| 項目 | 行號 | 用途 |
|---|---|---|
| `RESULT_SEARCH_ENABLED` | 86 | **搜尋功能的開關**。`false` = 關閉，`true` = 開啟 |
| 關閉時的設定 | 87～92 | 搜尋框設成無法輸入，加上提示「搜尋功能目前已關閉」，框裡的文字換成「目前搜尋功能關閉」 |
| 搜尋框的 `input` 事件 | 94 | 開關打開時，輸入後 0.15 秒依機種名稱篩選（包含就算符合，大小寫不分），再重新畫清單；關閉時直接略過 |

## 頁面載入的流程

```
頁面打開
  → loadData()
  → fetchModelCounts()      經 /api/db 讀出 model_shipment_counts
                              （伺服器已依數量由多到少排序）
  → maxQty = 第一筆的數量
  → updateSummary()         更新「機種數」和「總出貨量」
  → renderList()            畫出每個機種的長條圖
```

## 要修改時看這裡

| 想改什麼 | 改哪裡 |
|---|---|
| 搜尋功能開關 | 第 86 行 `RESULT_SEARCH_ENABLED` |
| 長條圖的計算方式 | 第 48 行 |
| 匯出的欄位 | 第 108～110 行 |
| 數量是怎麼算出來的 | 資料庫裡的 `model_shipment_counts` view（不在這個檔案裡） |

## 注意
- **匯出 CSV 一律匯出全部機種**，就算搜尋開關打開、畫面上只顯示篩選後的結果，匯出的還是完整清單。
- **長條圖的長度依賴「伺服器已經排好序」**：`maxQty` 直接取第一筆。如果以後改了伺服器的排序方式，長條圖比例會跑掉。
- 第 91 行後面的註解 `// ← 加這一行` 是從之前的說明複製過來的，可以刪掉，不影響運作。
- 如果資料庫裡有機種是空值，搜尋開關打開時，第 99 行的 `model.toLowerCase()` 會出錯。目前搜尋是關閉的，所以不會發生；以後要打開搜尋的話，建議改成 `(model || '').toLowerCase()`。
